# 🎓 IEM Events | CSE (AIML)

### Department Event Management Website — Institute of Engineering & Management, Kolkata

A modern, responsive and interactive event management website designed for the Department of Computer Science & Engineering (Artificial Intelligence and Machine Learning) at the Institute of Engineering & Management (IEM), Kolkata.

The website provides a centralized platform for exploring upcoming events, registering for activities, viewing event galleries, learning about the department and contacting the event team.

---

## 🌐 Live Demo

🚀 **[Visit IEM Events — CSE (AIML)](https://gregarious-fenglisu-5e088a.netlify.app)**

Explore the live website to see upcoming events, event registration, the gallery, department information and more.

---



## ✨ Features

- **Modern Landing Page** — An elegant hero section featuring a premium navy-blue, purple and cyan gradient design.
- **Upcoming Events** — Browse technical, workshop, cultural and guest lecture events.
- **Event Filtering** — Filter events by category, including Technical, Workshop, Cultural and Lecture.
- **Event Registration** — Registration form with student name, roll number, department, email, phone number, gender and event selection.
- **Event Gallery** — A visual collection of event posters and promotional graphics.
- **Department Information** — Information about the CSE (AIML) department, its academic focus and learning approach.
- **Event Coordinators** — Dedicated section showcasing faculty and student coordinators.
- **Live Event Countdown** — Countdown timer for the upcoming HackIEM 2026 event.
- **Contact & Feedback** — Contact section with a feedback form.
- **Dark/Light Theme** — Theme toggle for a more personalized browsing experience.
- **Responsive Design** — Designed for desktop, tablet and mobile screens.
- **Smooth Navigation** — Navigation links for Home, Events, Register, Gallery, About Us and Contact.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `style.css`, `script.js` and the `images` folder are in the correct locations.
4. Open `index.html` using the **Live Server** extension.
5. View the website in your browser.

Alternatively, open `index.html` directly in a web browser.
